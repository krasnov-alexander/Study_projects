# Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области

## Описание проекта

Агентство недвижимости из Петрозаводска планирует выйти на рынок Санкт-Петербурга и Ленинградской области и перенести основной офис в новый регион. Для подготовки бизнес-стратегии необходимо изучить рынок жилой недвижимости и определить наиболее перспективные сегменты.

В исследовании используются архивные данные объявлений о продаже квартир. Основная часть анализа посвящена времени активности объявлений и сезонности рынка. Дополнительно проводится сравнение отдельных населенных пунктов.

Помимо SQL-анализа, в рамках проекта доработан интерактивный дашборд в Yandex DataLens для оперативного анализа рынка и работы с клиентскими запросами.

**Цель исследования** - изучить рынок жилой недвижимости Санкт-Петербурга и Ленинградской области, определить особенности наиболее быстро и медленно снимаемых объявлений, выявить сезонные изменения активности и сравнить показатели между отдельными сегментами рынка.

В рамках исследования необходимо:

- сравнить объявления по времени их активности;
- определить характеристики объектов, связанные со сроком активности объявления;
- сравнить рынок Санкт-Петербурга и городов Ленинградской области;
- выявить сезонные изменения в публикации и снятии объявлений;
- дополнительно сравнить показатели рынка по отдельным населенным пунктам;
- представить основные показатели рынка в интерактивном дашборде.

## Используемые инструменты

- PostgreSQL
- DBeaver
- Yandex DataLens

## 1. Анализ времени активности объявлений

Первый этап анализа посвящен времени активности объявлений. В рамках проекта снятие объявления рассматривается как возможный признак продажи объекта, поскольку прямых данных о совершенных сделках в базе нет.

Объявления разделены на пять категорий:

- `1-30 days` - до одного месяца;
- `31-90 days` - от одного до трех месяцев;
- `91-180 days` - от трех месяцев до полугода;
- `181+ days` - более полугода;
- `non category` - объявления без указанного срока активности.

Для сравнения используются только объявления о недвижимости в городах за 2015-2018 годы.

### 1.1. Подготовка данных

Сначала определим границы аномальных значений и оставим объявления с корректными характеристиками. После этого добавим регион, категорию времени активности и стоимость квадратного метра.

```sql
WITH limits AS (
    SELECT
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY total_area) AS total_area_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY rooms) AS rooms_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY balcony) AS balcony_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY ceiling_height) AS ceiling_height_limit_h,
        PERCENTILE_DISC(0.01) WITHIN GROUP (ORDER BY ceiling_height) AS ceiling_height_limit_l
    FROM real_estate.flats
),

filtered_id AS (
    SELECT id
    FROM real_estate.flats
    WHERE total_area < (SELECT total_area_limit FROM limits)
        AND (
            rooms < (SELECT rooms_limit FROM limits)
            OR rooms IS NULL
        )
        AND (
            balcony < (SELECT balcony_limit FROM limits)
            OR balcony IS NULL
        )
        AND (
            (
                ceiling_height < (SELECT ceiling_height_limit_h FROM limits)
                AND ceiling_height > (SELECT ceiling_height_limit_l FROM limits)
            )
            OR ceiling_height IS NULL
        )
),

flats_filtered AS (
    SELECT *
    FROM real_estate.flats
    WHERE id IN (SELECT id FROM filtered_id)
),

flats_categorized AS (
    SELECT
        ff.id,
        ff.city_id,
        ff.type_id,
        ff.total_area,
        ff.rooms,
        ff.ceiling_height,
        ff.floors_total,
        ff.living_area,
        ff.floor,
        ff.is_apartment,
        ff.open_plan,
        ff.kitchen_area,
        ff.balcony,
        ff.airports_nearest,
        ff.parks_around3000,
        ff.ponds_around3000,
        CASE
            WHEN c.city = 'Санкт-Петербург'
                THEN 'Санкт-Петербург'
            ELSE 'Ленинградская обл.'
        END AS region,
        CASE
            WHEN a.days_exposition BETWEEN 1 AND 30
                THEN '1-30 days'
            WHEN a.days_exposition BETWEEN 31 AND 90
                THEN '31-90 days'
            WHEN a.days_exposition BETWEEN 91 AND 180
                THEN '91-180 days'
            WHEN a.days_exposition >= 181
                THEN '181+ days'
            ELSE 'non category'
        END AS activity,
        a.last_price::REAL / ff.total_area AS price_per_sqm,
        a.last_price
    FROM flats_filtered AS ff
    JOIN real_estate.advertisement AS a
        ON a.id = ff.id
    JOIN real_estate.city AS c
        ON c.city_id = ff.city_id
    JOIN real_estate.type AS t
        ON t.type_id = ff.type_id
    WHERE t.type = 'город'
        AND a.first_day_exposition >= '2015-01-01'
        AND a.first_day_exposition < '2019-01-01'
)
```

### 1.2. Сравнение объявлений по времени активности

Для каждой категории рассчитаем количество и долю объявлений, среднюю стоимость квартиры и квадратного метра, характеристики площади, а также медианные значения количества комнат, балконов, этажа и этажности дома.

```sql
SELECT
    region,
    activity,
    COUNT(*) AS flats_count,
    ROUND(
        COUNT(*)::NUMERIC
        / SUM(COUNT(*)) OVER (PARTITION BY region),
        2
    ) AS flats_share,
    ROUND(AVG(last_price)::NUMERIC, 2) AS avg_price,
    ROUND(AVG(price_per_sqm)::NUMERIC, 2) AS avg_price_per_sqm,
    ROUND(AVG(total_area)::NUMERIC, 2) AS avg_total_area,
    ROUND(AVG(kitchen_area)::NUMERIC, 2) AS avg_kitchen_area,
    ROUND(AVG(ceiling_height)::NUMERIC, 2) AS avg_ceiling_height,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY rooms) AS median_rooms,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY balcony) AS median_balconies,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY floor) AS median_floor,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY floors_total) AS median_floors_total
FROM flats_categorized
GROUP BY region, activity
ORDER BY region DESC, activity;
```

По количеству объявлений структура двух рынков похожа. В Санкт-Петербурге самая крупная категория - объявления со сроком активности более 180 дней (31%), затем идут 31-90 дней (27%) и 91-180 дней (20%). В городах Ленинградской области по 31% приходится сразу на две категории: 31-90 дней и более 180 дней. Быстрее чем за месяц снимаются 16% объявлений в Санкт-Петербурге и 12% в Ленинградской области.

В Санкт-Петербурге более долгий срок активности связан прежде всего с большей площадью и стоимостью объекта. У объявлений, снятых за 1-30 дней, средняя площадь квартиры составляет 54,7 м², средняя стоимость - 6,1 млн рублей, а стоимость квадратного метра - 108,9 тыс. рублей. Для объявлений, которые оставались активными более 180 дней, средняя площадь уже составляет 65,8 м², стоимость - 8,0 млн рублей, а квадратный метр - 115,0 тыс. рублей. В Ленинградской области эта зависимость слабее: средняя площадь также увеличивается с 48,8 до 55,0 м², но стоимость квадратного метра у объявлений со сроком более 180 дней ниже, чем у снятых за первый месяц - 68,2 против 71,9 тыс. рублей.

Количество комнат, балконов и высота потолков между категориями почти не отличаются. В большинстве групп медиана составляет две комнаты и один балкон, поэтому по этим характеристикам явной связи со сроком активности не видно. При этом квартиры в Санкт-Петербурге во всех сопоставимых категориях заметно дороже квартир в городах Ленинградской области. Категория `non category` отличается более высокой площадью и стоимостью объектов, особенно в Санкт-Петербурге, но срок активности этих объявлений неизвестен, поэтому использовать ее для сравнения скорости снятия нельзя.

## 2. Анализ сезонности объявлений

Дальше посмотрим, меняется ли активность рынка в течение года. Для этого сравним количество опубликованных и снятых объявлений по месяцам, а также среднюю стоимость, цену квадратного метра и площадь квартир.

Как и в предыдущем разделе, в анализ входят только объявления в городах, опубликованные в полные календарные годы с 2015 по 2018. Месяц снятия объявления рассчитывается на основе даты публикации и количества дней его активности.

### 2.1. Подготовка данных

Перед расчетом сезонности применим те же ограничения по площади, количеству комнат, балконов и высоте потолков, которые использовались в предыдущем разделе.

```sql
WITH limits AS (
    SELECT
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY total_area) AS total_area_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY rooms) AS rooms_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY balcony) AS balcony_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY ceiling_height) AS ceiling_height_limit_h,
        PERCENTILE_DISC(0.01) WITHIN GROUP (ORDER BY ceiling_height) AS ceiling_height_limit_l
    FROM real_estate.flats
),

filtered_id AS (
    SELECT id
    FROM real_estate.flats
    WHERE total_area < (SELECT total_area_limit FROM limits)
        AND (
            rooms < (SELECT rooms_limit FROM limits)
            OR rooms IS NULL
        )
        AND (
            balcony < (SELECT balcony_limit FROM limits)
            OR balcony IS NULL
        )
        AND (
            (
                ceiling_height < (SELECT ceiling_height_limit_h FROM limits)
                AND ceiling_height > (SELECT ceiling_height_limit_l FROM limits)
            )
            OR ceiling_height IS NULL
        )
),

flats_filtered AS (
    SELECT *
    FROM real_estate.flats
    WHERE id IN (SELECT id FROM filtered_id)
)
```

### 2.2. Сезонность публикации объявлений

Сгруппируем объявления по месяцу публикации и рассчитаем их количество, среднюю стоимость квартиры, стоимость квадратного метра и площадь. Дополнительно присвоим месяцам ранг по количеству новых объявлений.

```sql
monthly_advertisement_addition AS (
    SELECT
        EXTRACT(MONTH FROM a.first_day_exposition)::INTEGER AS month,
        COUNT(*) AS ads_published,
        ROUND(AVG(a.last_price)::NUMERIC, 2) AS avg_price_published,
        ROUND(AVG(a.last_price / ff.total_area)::NUMERIC, 2)
            AS avg_price_per_sqm_published,
        ROUND(AVG(ff.total_area)::NUMERIC, 2) AS avg_area_published,
        RANK() OVER (ORDER BY COUNT(*) DESC) AS publication_rank
    FROM flats_filtered AS ff
    JOIN real_estate.advertisement AS a
        ON a.id = ff.id
    JOIN real_estate.type AS t
        ON t.type_id = ff.type_id
    WHERE t.type = 'город'
        AND a.first_day_exposition >= '2015-01-01'
        AND a.first_day_exposition < '2019-01-01'
    GROUP BY EXTRACT(MONTH FROM a.first_day_exposition)
)
```

### 2.3. Сезонность снятия объявлений

Для снятых объявлений определим месяц завершения активности как сумму даты публикации и количества дней размещения. После этого рассчитаем аналогичные показатели по месяцам.

```sql
monthly_advertisement_removal AS (
    SELECT
        EXTRACT(
            MONTH FROM a.first_day_exposition + a.days_exposition * INTERVAL '1 day'
        )::INTEGER AS month,
        COUNT(*) AS ads_removed,
        ROUND(AVG(a.last_price)::NUMERIC, 2) AS avg_price_removed,
        ROUND(AVG(a.last_price / ff.total_area)::NUMERIC, 2)
            AS avg_price_per_sqm_removed,
        ROUND(AVG(ff.total_area)::NUMERIC, 2) AS avg_area_removed,
        RANK() OVER (ORDER BY COUNT(*) DESC) AS removal_rank
    FROM flats_filtered AS ff
    JOIN real_estate.advertisement AS a
        ON a.id = ff.id
    JOIN real_estate.type AS t
        ON t.type_id = ff.type_id
    WHERE t.type = 'город'
        AND a.days_exposition IS NOT NULL
        AND a.first_day_exposition >= '2015-01-01'
        AND a.first_day_exposition < '2019-01-01'
    GROUP BY EXTRACT(
        MONTH FROM a.first_day_exposition + a.days_exposition * INTERVAL '1 day'
    )
)
```

### 2.4. Сравнение публикации и снятия объявлений

Объединим результаты по месяцам и добавим сезон года.

```sql
SELECT
    CASE
        WHEN maa.month IN (12, 1, 2) THEN 'Winter'
        WHEN maa.month IN (3, 4, 5) THEN 'Spring'
        WHEN maa.month IN (6, 7, 8) THEN 'Summer'
        WHEN maa.month IN (9, 10, 11) THEN 'Autumn'
    END AS season,
    maa.month,
    maa.ads_published,
    maa.publication_rank,
    mar.ads_removed,
    mar.removal_rank,
    maa.avg_price_published,
    mar.avg_price_removed,
    maa.avg_price_per_sqm_published,
    mar.avg_price_per_sqm_removed,
    maa.avg_area_published,
    mar.avg_area_removed
```

## 3. Дополнительный анализ населенных пунктов

### 3.1. Подготовка данных

Для дополнительного анализа используем те же границы аномальных значений, что и в предыдущих разделах.

```sql
WITH limits AS (
    SELECT
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY total_area) AS total_area_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY rooms) AS rooms_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY balcony) AS balcony_limit,
        PERCENTILE_DISC(0.99) WITHIN GROUP (ORDER BY ceiling_height) AS ceiling_height_limit_h,
        PERCENTILE_DISC(0.01) WITHIN GROUP (ORDER BY ceiling_height) AS ceiling_height_limit_l
    FROM real_estate.flats
),

filtered_id AS (
    SELECT id
    FROM real_estate.flats
    WHERE total_area < (SELECT total_area_limit FROM limits)
        AND (
            rooms < (SELECT rooms_limit FROM limits)
            OR rooms IS NULL
        )
        AND (
            balcony < (SELECT balcony_limit FROM limits)
            OR balcony IS NULL
        )
        AND (
            (
                ceiling_height < (SELECT ceiling_height_limit_h FROM limits)
                AND ceiling_height > (SELECT ceiling_height_limit_l FROM limits)
            )
            OR ceiling_height IS NULL
        )
),

flats_filtered AS (
    SELECT *
    FROM real_estate.flats
    WHERE id IN (SELECT id FROM filtered_id)
)
```

### 3.2. Показатели по населенным пунктам

Для каждого населенного пункта рассчитаем количество опубликованных и снятых объявлений, долю снятых объявлений, среднюю стоимость квартиры и квадратного метра, характеристики площади, медианное количество комнат и среднее время активности. После этого оставим 15 населенных пунктов с наибольшим количеством снятых объявлений.

```sql
locality_stats AS (
    SELECT
        c.city AS locality,
        COUNT(*) AS ads_published,
        COUNT(a.days_exposition) AS ads_removed,
        ROUND(
            COUNT(a.days_exposition)::NUMERIC / COUNT(*),
            2
        ) AS ads_removed_share,
        ROUND(AVG(a.last_price)::NUMERIC, 2) AS avg_price,
        ROUND(
            AVG(a.last_price / ff.total_area)::NUMERIC,
            2
        ) AS avg_price_per_sqm,
        ROUND(AVG(ff.total_area)::NUMERIC, 2) AS avg_total_area,
        ROUND(AVG(ff.kitchen_area)::NUMERIC, 2) AS avg_kitchen_area,
        PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY ff.rooms)
            AS median_rooms,
        ROUND(AVG(a.days_exposition)::NUMERIC, 0)
            AS avg_days_exposition
    FROM flats_filtered AS ff
    JOIN real_estate.advertisement AS a
        ON a.id = ff.id
    JOIN real_estate.city AS c
        ON c.city_id = ff.city_id
    WHERE c.city <> 'Санкт-Петербург'
    GROUP BY c.city
    ORDER BY ads_removed DESC
    LIMIT 15
)
```

### 3.3. Скорость снятия объявлений

Чтобы сравнить населенные пункты по времени активности объявлений, разделим их на три группы. Границы групп определим по 33-му и 66-му перцентилям среднего срока активности среди выбранных населенных пунктов.

```sql
, quantiles AS (
    SELECT
        PERCENTILE_CONT(0.33) WITHIN GROUP (ORDER BY avg_days_exposition) AS q33,
        PERCENTILE_CONT(0.66) WITHIN GROUP (ORDER BY avg_days_exposition) AS q66
    FROM locality_stats
)

SELECT
    ls.*,
    CASE
        WHEN ls.avg_days_exposition <= q.q33
            THEN 'быстрая'
        WHEN ls.avg_days_exposition <= q.q66
            THEN 'умеренная'
        WHEN ls.avg_days_exposition > q.q66
            THEN 'медленная'
        ELSE 'нет данных'
    END AS removal_speed
FROM locality_stats AS ls
CROSS JOIN quantiles AS q
ORDER BY ls.ads_removed DESC;
```

## 5. Итоговые выводы и рекомендации

Анализ показал, что рынок Санкт-Петербурга и других населенных пунктов заметно различается по стоимости недвижимости и характеристикам объявлений. В Санкт-Петербурге квартиры во всех рассмотренных категориях активности стоят дороже. При этом объявления, которые снимаются быстрее, в среднем относятся к менее крупным и более дешевым объектам. Например, средняя площадь квартир со сроком активности до 30 дней составляет 54,7 м², а со сроком более 180 дней - 65,8 м². Для других населенных пунктов связь между сроком активности и стоимостью выражена слабее.

Активность рынка меняется в течение года. Больше всего новых объявлений публикуется осенью: максимум приходится на ноябрь, а по снятию объявлений - на октябрь. Наименьшая активность наблюдается в мае, а по публикациям также выделяется январь. При этом средняя площадь и стоимость квадратного метра меняются по месяцам значительно меньше, поэтому сезонность сильнее проявляется именно в количестве объявлений.

Дополнительное сравнение населенных пунктов показало различия как по стоимости недвижимости, так и по среднему времени активности объявлений. Среди 15 населенных пунктов с наибольшим количеством снятых объявлений самые низкие средние сроки получены для Колпино, Мурино и Шушар, а самые высокие - для Сестрорецка, Красного Села, Пушкина и Петергофа. По стоимости квадратного метра среди рассмотренных населенных пунктов выделяются Пушкин и Сестрорецк, где среднее значение превышает 100 тыс. рублей за м².

При выходе на новый рынок агентству стоит учитывать различия между Санкт-Петербургом и отдельными населенными пунктами и не рассматривать их как один однородный рынок. Для продвижения объектов также можно учитывать сезонность: осенью одновременно растет активность по публикации и снятию объявлений. При работе с конкретным объектом полезно сравнивать его не только по цене, но и по площади, расположению и характерному для выбранного сегмента времени активности.

Подготовленный дашборд в Yandex DataLens можно использовать для дальнейшей работы с рынком: выбирать нужные населенные пункты и типы недвижимости, отслеживать динамику основных показателей и быстро получать срез данных под конкретный клиентский запрос. При этом снятие объявления используется в исследовании как приближенный показатель продажи, поэтому результаты по скорости стоит рассматривать именно как анализ активности объявлений, а не подтвержденных сделок.
