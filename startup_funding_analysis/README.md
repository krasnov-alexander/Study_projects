# Анализ рынка стартапов и сделок по их приобретению

## О проекте

Исследование рынка стартапов, раундов финансирования и сделок по приобретению компаний. Цель проекта — изучить особенности финансирования стартапов, стоимость сделок и характеристики компаний, которые могут быть полезны при оценке потенциальных инвестиционных возможностей.

## Основные задачи

* исследовать динамику количества и размера раундов финансирования;
* оценить качество и полноту данных;
* изучить распределение общего объема финансирования компаний;
* проанализировать сделки стоимостью 0 или 1 доллар;
* сравнить стоимость приобретения стартапов разных категорий;
* сравнить количество раундов финансирования компаний с разными статусами.

## Данные

В исследовании используются данные о стартапах, раундах финансирования, сделках по приобретению компаний, сотрудниках и их образовании.

## Инструменты

Python, Pandas, NumPy, Matplotlib, Seaborn.

## Основные результаты

Количество раундов финансирования заметно росло в рассматриваемом периоде, одновременно с этим типичный размер одного раунда снижался.

Распределение общего финансирования компаний сильно смещено вправо: медиана составляет около 600 тыс. долларов, тогда как среднее превышает 10 млн долларов.

Среди рассмотренных категорий наиболее высокая медианная стоимость приобретения наблюдается у Manufacturing, Biotech и Cleantech. При этом Biotech также отличается высоким разбросом стоимости сделок.

Большинство компаний проходит небольшое количество раундов финансирования: медиана по выборке составляет один раунд.
